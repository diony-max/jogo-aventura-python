# 🎮 Jogo de Aventura em Python

Um jogo de aventura baseado em texto desenvolvido em Python. O projeto foi criado com o objetivo de aplicar conceitos fundamentais de programação, incluindo estruturas condicionais, laços de repetição, funções e controle de fluxo.

## 📌 Objetivos do projeto

* Praticar a lógica de programação.
* Desenvolver um sistema de tomada de decisões.
* Implementar diferentes caminhos narrativos.
* Trabalhar com estruturas de controle e interação com o usuário.

## 🚀 Funcionalidades

* Sistema de narrativa interativa.
* Escolhas que influenciam o desenvolvimento da história.
* Sistema de vidas.
* Sistema de pontuação.
* Diferentes finais, dependendo das decisões do jogador.

## 🛠️ Tecnologias utilizadas

* Python

## ▶️ Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/diony-max/jogo-aventura-python.git
```

2. Acesse a pasta do projeto:

```bash
cd jogo-aventura-python
```

3. Execute o jogo:

```bash
python jogo_aventura.py
```

## 💡 Conceitos aplicados

* Estruturas condicionais.
* Laços de repetição.
* Funções.
* Variáveis.
* Entrada e saída de dados.
* Controle de fluxo.
